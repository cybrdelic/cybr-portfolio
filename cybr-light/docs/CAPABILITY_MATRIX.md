# CYBR LIGHT 0.2 capability and evidence matrix

Supported features, executed checks, and remaining limitations of the native CYBR LIGHT engine. Test results apply to the scenarios and models exercised; they do not establish arbitrary-scene optical correctness.

| Subsystem | Supplied implementation and executed evidence | Remaining boundary |
|---|---|---|
| Spectral transport | Native scalar-wavelength path tracing, correlated stratified wavelength packets, Cauchy dispersion, Beer absorption; original scenes re-executed. | Analytic observer and coarse authoring-control spectra by default; no measured-optics parity benchmark. |
| Native geometry | SAH BVH, smooth triangles and UVs, spheres/quads, exact disks/cylinder sides, caps as disks, OBJ/ASCII and binary PLY import. Numerical intersection/area checks. | No curve/hair primitive, displacement tessellator, CAD kernel, instanced acceleration sharing, or arbitrary user intersection callbacks. |
| Materials | Diffuse, anisotropic GGX conductor/rough dielectric, smooth glass/mirror, limited plastic, null/retarder/polarizer, thin dielectric, diffuse transmission, masks/blends, normal/bump maps. New material and sampling checks and images. | GGX rather than Beckmann parity; no BSSRDF/hair/measured multilayer model/microfacet multiple scattering. Dielectric-medium mixtures rejected. |
| Nested media | Native dynamic-spill medium stack, identity-preserving boundary transitions, absorption/dispersion, bubble regression scenes. Portable stack checked up to 64. | Well-formed nesting; arbitrary overlapping solids unresolved. Initial camera medium not inferred. |
| Light sampling | Area, point, directional, spot, enclosing environment; environment PFM importance grid; power MIS including through-null probability. Transparent-shadow and inverse-square checks. | No projector/IES/laser plugins; no emitter-plugin ABI compatibility. |
| Volumes | Homogeneous and bounded grid/procedural heterogeneous free flight, delta/ratio tracking, HG/isotropic/Rayleigh. Scalar VOL v3 container conversion checked. | Axis-aligned domains; no OpenVDB traversal, general shape-attached overlapping media, spatially varying RGB albedo grid, or spectral-distance MIS implementation. |
| Polarization | Full stored Stokes components; ideal optics, rough-surface Mueller operators, polarized Rayleigh multiple scattering. Physical-Stokes unit checks and analyzer/degree-of-polarization outputs. | No native joint AD/polarization; thin-sheet polarized model rejected; diffuse/HG depolarizing models; not validated against measured optics or all frame configurations. |
| Cameras | Pinhole, thin-lens, orthographic, spherical; translating primitives and shutter sampling. Legacy DOF/motion scenes re-executed. | No multi-element lens, rotation/deformation motion, rolling shutter, finite sensor clipping, or multiple simultaneous sensors. |
| Integrators | Path/volume path, direct, AO, shared-scene camera photon mapper, original forward photon detector. | Photon mapper is biased, surface-only, finite-band; no unbiased general BDPT/VCM/MLT, guiding, transient engine, or arbitrary integrator-plugin ABI. |
| Sampling/filters | Independent PCG, random-shift Halton first 64 dimensions with PCG fallback; box/tent/Gaussian/Mitchell/Lanczos. Density, moment, normalization, and determinism checks. | Sampler sequences and reconstruction-filter parameters are specific to this implementation. |
| Film/output | Raw PFM and independent uncompressed float32 scanline EXR writer; PNG display; diagnostic AOV/gradient/Stokes buffers. EXR independently decoded to exactly equal float32 pixels. | No compressed/deep/multipart EXR. AOV diagnostics are center samples, albedo is authoring controls, normal is [0,1]. Arbitrary named/filtered auxiliary channels are not implemented. |
| Scene API | Python builders; checked XML/dictionary subset, named references, affine transforms, flattened instances, custom compilation factories, transactional traversal, snapshots, bundles. Import/rollback/relocation tests. | Not a drop-in XML/plugin/API implementation. Plugin factories compile to existing native primitives/BSDFs, not arbitrary external plugin classes. Spectral RGB semantics differ. |
| Native shader compiler | Original expression DAG, generated/executed C++17, reverse derivatives, symbolic second derivatives, stable sigmoid/branch operations, source/graph/compile receipts, material-shader ABI. Eager/compiled/FD and higher-derivative tests. | Elementwise graphs; no general reductions, scatter/gather, lazy/dynamic control flow, GPU lowering. C++ compiler required. |
| Image AD | Native dual-number transport for three selected diffuse/shader controls; copied nested shader identities preserve derivatives. All three rendered shader derivatives checked against raw-image central differences. | Not arbitrary geometry/camera/roughness/IOR/volume/texture-field AD. No general visibility discontinuity estimator or full differentiable renderer. |
| General inverse workflow | Checked finite-difference scene rerendering, bounded LM, declared optional loss filter, transactional geometry/camera/light/material/volume controls. Executed two-parameter geometry fit and held-out seed. | Numeric differentiation, not AD. Step-size bias and potentially high sampling variance; not scalable to millions of scene variables. Synthetic self-consistency test, not photo reconstruction. |
| Portable CPU/CUDA source | Shared Numba scalar transport, threaded BVH, smooth meshes and analytic geometry, rough/smooth surfaces, nested media, point/area/environment sampling. CPU render, 1,000-ray BVH oracle, same-image CUDA simulator comparison. | **No physical CUDA compile/run verification.** Simulator does not type-check device code. No OptiX/RTX. Portable backend rejects volumes/polarization/AD/textures/shaders and other unsupported combinations. |
| Native OptiX surface backend (opt-in) | Physical RTX 4060 Laptop execution; native spectral tables, coated glass, nested water, anisotropic metals, environment/area-light MIS, emissive surfaces, point/sun/spot lights, triangle/quad traversal, AOVs and checkpoint resume. Synthetic and actual instrument CPU/GPU comparisons; exact GPU resume on the tested configuration. See [OPTIX.md](OPTIX.md). | Surface subset only; not the Numba backend and not full CPU feature parity. Unsupported features fail explicitly. Float RT geometry, double shading/film; no universal speedup or cross-device bitwise-parity claim. |
| Checkpoint/resume | Scene/asset signatures, checksum, atomic replacement, mismatch/corruption rejection, exact continuation across thread counts; bitwise film and derivative comparison. | Native ABI/version-specific files, not universal portable checkpoints. No distributed renderer/scheduler. |
| Packaging | Source and execution evidence, frozen examples, generated shader source, asset manifests, rebuild commands, fresh archive integrity and clean extraction checks. | Recovered native implementation published in cybrdelic/cybr-light. No CYBR GEO default change; no production-deployment claim. |

The optional earlier tensor example still uses PyTorch/TorchScript. It is separate from the new independent expression compiler and relies on PyTorch for its compiler and automatic differentiation. Older archived test results are kept in `baseline_evidence`; current results live in `evidence`.
