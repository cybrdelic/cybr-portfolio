# Typographic project index

The portfolio opens with six project names on burgundy, using the existing
Cybrdelic sigil. No Three.js scene, model package or video loads at startup.
Lightweight SVG gestures identify the disciplines without serving as measured
project data.

Hover a name on desktop, focus it with the keyboard, or select it to reveal
project media. On phones the preview appears inside the selected project row.
The separate arrow and preview link open the existing project page. Escape or
the close button dismisses the preview and releases its media sources.

GEO and LIGHT use the retained specimen demonstrations. ELEMENTS shows the
water sigil simulation film; COMBAT shows the side-view leap. SONG presents
the retained score and user-controlled Lantern Steps recording. SCENES uses
the existing Quiet Observatory IV render. There are no generated concept
images or fabricated project artifacts in the implementation.

Playback is muted except for the explicit audio control. Reduced motion
disables automatic video playback. Switching projects pauses and clears the
previous video and audio; leaving the page visible state pauses playback.

Validation: JavaScript syntax check; 1,269 local HTML references with no
missing files; nine retained films validated. Browser review at desktop,
390 px and 320 px widths covered all six routes, media switching, inline
phone preview, keyboard activation and Escape. No console errors observed.
